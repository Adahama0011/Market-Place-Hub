Security Policy

Supported Versions

This project is actively maintained. Security updates will be applied to the latest version whenever possible.

Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by opening a private issue or contacting the project maintainer.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fixes (if available)

Sensitive security issues will be reviewed promptly, and appropriate action will be taken to resolve them.

Thank you for helping improve the security of this project.
