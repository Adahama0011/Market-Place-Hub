🛒 Marketplace Hub

A modern, responsive Marketplace Hub built with React, TypeScript, Vite, and Tailwind CSS. The platform provides an engaging marketplace experience where users can browse featured deals, explore trending categories, and view detailed product information through a clean and intuitive interface.

✨ Features

- 🎥 Modern hero section with background video
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🔥 Featured deals showcase
- 🛍️ Trending product categories
- 📄 Individual deal detail pages
- ✨ Smooth scroll animations
- 🎨 Modern UI powered by Tailwind CSS
- ⚡ Fast performance with Vite
- 🧩 Reusable React components
- 📂 Organized and scalable project structure

🛠️ Built With

- React
- TypeScript
- Vite
- Tailwind CSS
- CSS3
- HTML5

📁 Project Structure

src/

public/

└── videos/               # Background video assets

🚀 Getting Started

Prerequisites

- Node.js (v18 or later)
- npm or yarn

Installation

git clone https://github.com/Adahama0011/marketplace-hub.git

cd marketplace-hub

npm install

npm run dev

Open your browser and visit:

http://localhost:5173

📦 Build for Production

npm run build

Preview the production build:

npm run preview
